# UniHub 方向与路线图

> 当前方向、近期目标、已知缺口。定期更新。

---

## 当前方向（2026-05）

UniHub 定位为 **本地优先的个人知识管理工具箱**，核心原则：

| 原则 | 说明 |
|------|------|
| 离线可用 | 所有数据本地 SQLite 存储，无强制网络依赖 |
| 数据主权 | 数据完全归用户，纯文件系统管理（导出/备份友好） |
| 桌面优先 | 首屏体验对 Windows 桌面深度优化，响应式适配移动端 |
| 插件化 | 核心功能通过插件系统解耦，降低维护复杂度 |

### 已实现

- ✅ Thoughts 想法管理（AppFlowy 富文本、标签、图片、搜索）
- ✅ Collections 内容收藏（链接保存、元数据抓取、Box 归类）
- ✅ Dashboard 首页（统计、最近想法、焦点模块）
- ✅ 响应式布局（三档断点 ≤900 / 900-1279 / ≥1280）
- ✅ 6 套主题预设
- ✅ 插件系统接口

## 已知缺口

| 缺口 | 影响 | 备注 |
|------|------|------|
| 图片编辑器集成 | AppFlowy image block 尚未接入 | 图片暂通过独立 `imagePaths` 字段管理 |
| 批量 Quill 数据迁移 | 旧 `unihub.quill_delta.v1` 数据不显示摘要 | 编辑时自动升级 |
| 插件通用 CRUD 模板 | 每个插件重复 DAO/Repository/Provider | 可考虑提取模板或代码生成 |
| E2E / Integration 测试 | 缺少完整用户流测试 | 当前以 Widget 测试为主 |
| CI 流程 | 无自动 lint + test 流水线 | 本地手动验证 |
| 离线 fallback 策略 | 当前纯离线，后续同步机制待设计 | 无紧急需求 |
| 国际化 (i18n) | 全中文 UI，无英文/多语言支持 | P3 |

## 已关闭方向

- **纯笔记应用定位**：2026-05 从「笔记应用」调整为「个人工具箱」，编辑器从 Quill 迁到 AppFlowy
- **flomo 同步/导入**：早期考虑过，当前无计划
- **移动端优先**：设计上桌面端优先，移动端自适应但不作为主力场景
