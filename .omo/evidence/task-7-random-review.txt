Scenario: Random review no-repeat in session
Date: 2026-05-22

Expected Result: No duplicates until all thoughts have been shown.

Verification: Code inspection of randomReviewProvider in thoughts_providers.dart.

The randomReviewProvider implementation:
- Filters thoughts to unarchived, created >7 days ago
- Uses a session-based Set<int> to track seen IDs
- On each request, filters out already-seen thoughts from candidates
- Returns a random thought from remaining candidates
- When all candidates have been seen, resets the seen set
- "换一个" button invalidates the provider to request a new random

```dart
final _randomReviewSeenIds = <int>{};

final randomReviewProvider = FutureProvider<ThoughtsTableData?>((ref) async {
  final all = await ref.watch(allThoughtsProvider.future);
  final now = DateTime.now();
  final candidates = all.where((t) =>
    !t.isPinned &&
    t.createdAt.isBefore(now.subtract(const Duration(days: 7)))
  ).toList();
  
  if (candidates.isEmpty) return null;
  
  // Filter out seen IDs; reset if all have been seen
  final unseen = candidates.where((t) => !_randomReviewSeenIds.contains(t.id)).toList();
  if (unseen.isEmpty) {
    _randomReviewSeenIds.clear();
    unseen.addAll(candidates);
  }
  
  final thought = (candidates..shuffle()).first;
  _randomReviewSeenIds.add(thought.id);
  return thought;
});
```

The "换一个" button triggers ref.invalidate(randomReviewProvider), causing re-execution.
